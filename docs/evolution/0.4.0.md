# Engram 0.4.0 · First current-core public package

## Problem

多个宿主共享知识时，旧关键词或嵌入可能继续命中已经明确纠正的记录，相关上下文也未必触发检索。此前公开源码标为 0.1.0，没有正式 release/tag；这份包公开当前核心，不补造中间版本发布。

## Architecture and interface

保留单一 SQLite 事实源、正文/FTS/outbox 的原子写入和异步语义层。增加明确 `corrections`、只读 `current` 投影、保原文的 `history/get`、读取状态、软项目偏置与显式关键词降级。共享 MLX 和远程认证合同支持多宿主；Claude Code keyword Hook 按相关性与版本变化提供有界上下文。

公开包排除源码发布运行器、部署网关、实际运行数据和个人配置；受控内容维护与固定证据模块作为可复用源码保留。

## Decisions and alternatives

复用既有 records、attributes、revisions、links、FTS、向量和 RRF，不另建事实库或常驻事实裁决模型。只接受明确纠正，不按年龄或相似度推断失效。无法定位、基线变化或重叠时保留来源与不确定性，不猜测自动替换。

公开副本将设备标签泛化、日程改为显式配置且默认 manual，并将服务图标改为原生 SVG；原 `/icon.png` URL 保留兼容响应，MIME 为 SVG。访问保护不减少，实际个人配置不随包分发。

公开复审修复 ASGI 保留前缀时的认证绕过，并让显式队列/超时使用同一路由路径；仅设置超时的配置不再释放不存在的 limiter。初始化图标元数据与 SVG 响应一致。刷新轮换保留旧令牌 hashed key 的 client/resource/family 关联及原始到期时间；同 grant 的重放撤销活动 family，并在事务提交后才返回 invalid_grant。复用原 objects 表和既有授权流程，不保存旧令牌明文、不增加授权层，也不宣称原私有部署已更新。

## Research hypotheses

显式纠正与 current/history 可降低旧证据被误作当前结论的风险；软项目偏置可减少登记门槛；相关时提示与版本变化再提示可提高当前知识的可见性。工程机制已经实现，真实任务收益仍是假设。RRF 的算法来源见[原论文](https://doi.org/10.1145/1571941.1572114)，论文成绩不作为 Engram 实测成绩。

## Validation and limits

SQLite 兼容修复：向量扩展在写事务前初始化一次，避免部分 SQLite 构建在 FTS 写入后重复初始化失败；写前/写后的完整性、外键与 FTS 覆盖门禁仍完整执行。 合成回归同时覆盖扩展调用次数和写前/写后拒绝路径。

完全虚构的传感器记录覆盖整条替代、旧词命中、历史保留、局部基线、重叠、事务回滚、模型降级、跨连接提交可见性和 Hook 同会话更新。认证测试使用临时状态与伪令牌；公开边界守卫拒绝实际数据格式、私有路径/URL/凭据/标识、软链接与未列出文件。

确定性向量只验证索引和接口。合成测试、模块导入与离线打包不证明真实用户收益、长时运行、全部宿主自动采用、真实语义精度或超大库完整召回。本版没有上传真实日志、记忆或匿名后的原始记录。

## Next

扩展完全合成的多跳/归档/局部并存反例和公开召回基准；分别衡量可见、取到、采用、正确行动，避免混为一个成功指标。语义资源与负载测量应另行设计可复现公开实验。每个后续版本同步 CHANGELOG、架构、演化说明及发布边界审查。
