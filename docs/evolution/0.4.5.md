# Engram 0.4.5

## Problem
Some cover illustrations showed a visible square boundary where the drawing ran to the image edge, and illustration sizes were tuned per repository.

## Architecture and interface
Replace the four covers. The illustration is cropped to its content, placed by one fixed rule (hard boundary, fade band, safe area) shared across repositories, and any side whose drawing reaches the image edge fades into the background. Update the pinned cover hashes; runtime interfaces are unchanged.

## Decisions and alternatives
No outpainting or regeneration; the drawing itself is unchanged apart from the edge fade. Parameters are fixed in one shared file and checked by script.

## Research hypotheses
None; this is a presentation change.

## Validation and limits
A scripted check confirms size, exact background, divider, signature, text column, hard boundary, no edge-touching lines and zero paper tint. Run the publication and test suites.
